# آرشام پوینت — Arsham Point

**ساخت پاورپوینت فارسی با هوش مصنوعی**

موضوع ارائه را می‌نویسید؛ **موتور هوش مصنوعی آرشام پوینت** (مبتنی بر مدل GLM) یک پرزنتیشن کامل، راست‌چین و آماده اجرا در مرورگر می‌سازد — با اسلاید جلد، دستور جلسه، آمار، نقل‌قول، خط زمانی، تصویر و جمع‌بندی. خروجی یک فایل HTML تک‌فایلی و مستقل است که می‌توانید اجرا، دانلود و نگه‌داری کنید.

سایت اصلی: [apoint.ir](https://apoint.ir) · نسخه ابری: [arshampoint.vercel.app](https://arshampoint.vercel.app)

---

## ✨ امکانات

- **تولید خودکار محتوا** — ساختار اسلایدها، متن‌ها، آمارها و نقل‌قول‌ها را موتور هوش مصنوعی آرشام پوینت در چند ثانیه می‌سازد
- **۱ تا ۱۰ اسلاید در پلن رایگان، تا ۱۴ اسلاید در حرفه‌ای** — اگر مدل کم آورد، مکانیزم «تکمیل خودکار» اسلایدهای جاافتاده را می‌سازد
- **۱۲ قالب طراحی هوشمند** — از مدرن و مینیمال تا شب نئون، آکادمیک و خط فارسی؛ انتخاب خودکار متناسب با موضوع (+ ۱۲ رنگ غالب) و انتخاب دستی در پلن حرفه‌ای
- **دو حالت متنی و تصویری** — در حالت تصویری برای هر اسلاید عکس مرتبط انتخاب می‌شود
- **خروجی HTML تک‌فایلی** — بدون هیچ وابستگی خارجی؛ روی هر مرورگر و هر سیستم‌عاملی یکسان اجرا می‌شود
- **نمایش حرفه‌ای** — ناوبری کیبورد، نمای کلی، تمام‌صفحه، ریموت لمسی و سوییچ لحظه‌ای تم شبانه/روشن برای مخاطب
- **افکت‌های لود** — ورود پلکانی بخش‌های صفحه اصلی و ظهور تدریجی هنگام اسکرول (با احترام به `prefers-reduced-motion`)
- **ورود پایدار** — نشست با کوکی ماندگار بازیابی می‌شود و گاردهای روتر باعث می‌شوند دکمه Back کاربر را از اپ بیرون نیندازد
- **استخر چندکلیدی** — چند کلید سرویس هوش مصنوعی در یک متغیر، با پرانتز از هم جدا؛ هر درخواست با یک کلید رندوم شروع می‌شود و اگر کلیدی شلوغ/بی‌اعتبار بود (۴۲۹/۴۰۱/۴۰۲/۴۰۳/۵xx/قطعی شبکه) کلید بعدی خودکار امتحان می‌شود (مناسب تیم‌های چندنفره). راهنمای کامل استفاده برای شریک‌ها: [`docs/multi-key-guide-fa.md`](docs/multi-key-guide-fa.md)
- **کتابخانه اختصاصی** — هر کاربر پرزنتیشن‌های خودش را ذخیره، اجرا و دانلود می‌کند
- **پلن رایگان و حرفه‌ای** — رایگان: ۳ ارائه در روز (پنجره لغزان ۲۴ ساعته) با نشان برند؛ حرفه‌ای: نامحدود و بدون نشان، دوره ۳۰ روزه با درگاه زرین‌پال
- **پیام‌های خطای فارسی و برند** — خطاها با نام «موتور هوش‌مصنوعی آرشام پوینت» یا «سرور» گزارش می‌شوند
- **صفحات کامل محصول** — خانه، امکانات، قیمت‌گذاری، بررسی سفارش، سوالات متداول، درباره ما، تماس، حریم خصوصی، قوانین، وبلاگ «آرشام پوینت مگ» + متادیتای سئو، JSON-LD، sitemap و robots

## 🧰 تکنولوژی

| لایه | ابزار |
|---|---|
| فریم‌ورک | Next.js 16 (App Router) + React 19 + TypeScript |
| استایل | Tailwind CSS 4 + shadcn/ui |
| پایگاه داده | Supabase Postgres (پروداکشن) / Prisma + SQLite (دموی محلی) |
| احراز هویت | Supabase Auth (پروداکشن) / کوکی امضاشده + بازیابی نشست (دموی محلی) |
| هوش مصنوعی | موتور آرشام پوینت روی API سازگار با OpenAI (`glm-4.6`) یا SDK داخلی در سندباکس |
| پرداخت | زرین‌پال (اشتراک ۳۰ روزه پلن حرفه‌ای) |

> **معماری دوحالته:** هر سه متغیر Supabase را تنظیم کنید → پروداکشن کامل؛ خالی بگذارید → دموی محلی بدون نیاز به هیچ کلیدی.

## 🚀 اجرای سریع

```bash
# ۱) نصب وابستگی‌ها (کلاینت Prisma هم خودکار ساخته می‌شود)
bun install        # یا: npm install

# ۲) متغیرهای محیطی
cp .env.example .env     # برای دموی محلی همان پیش‌فرض‌ها کافی است

# ۳) ساخت جداول دیتابیس محلی + داده نمونه
bun run db:push
bun scripts/seed-demo.ts

# ۴) اجرا
bun run dev        # http://localhost:3000
```

**حساب آزمایشی:** `demo@arshampoint.ir` / `123456` (در صفحه ورود دکمه ورود یک‌کلیکی هم دارد)

## 🔑 متغیرهای محیطی

| متغیر | ضرورت | توضیح |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | پروداکشن | Supabase → Settings → API → Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | پروداکشن | Supabase → Settings → API → anon public |
| `SUPABASE_SERVICE_ROLE_KEY` | پروداکشن | کلید service_role — فقط سمت سرور |
| `ZAI_API_KEY` | پروداکشن | کلید سرویس هوش مصنوعی — **تک‌کلید یا استخر چندکلیدی** (بخش پایین) |
| `ZAI_MODEL` | اختیاری | پیش‌فرض `glm-4.6` |
| `ZAI_BASE_URL` | اختیاری | پیش‌فرض `https://api.z.ai/api/paas/v4` |
| `AUTH_SECRET` | پیشنهادی | امضای کوکی سشن و callback پرداخت (`openssl rand -hex 32`) |
| `ZARINPAL_MERCHANT_ID` | پرداخت | مرچنت‌آی‌دی زرین‌پال؛ خالی باشد دکمه پرداخت «به‌زودی» می‌دهد |
| `ZARINPAL_AMOUNT_RIALS` | پرداخت | مبلغ درگاه به ریال — پیش‌فرض `1490000` (۱۴۹ هزار تومان) |
| `ZARINPAL_SANDBOX` | تست پرداخت | `1` = درگاه سندباکس رسمی زرین‌پال |
| `ZARINPAL_BASE_URL` | تست پرداخت | درگاه سفارشی/پروکسی — مقدم بر sandbox (فیک‌گیت‌وی E2E) |
| `FREE_DAILY_QUOTA` | اختیاری | سقف روزانه پلن رایگان — پیش‌فرض `3` |
| `PRO_PERIOD_DAYS` | اختیاری | طول هر دوره اشتراک به روز — پیش‌فرض `30` |
| `DATABASE_URL` | فقط دمو | مسیر SQLite محلی |
| `NEXT_PUBLIC_SITE_URL` | اختیاری | آدرس سایت برای متادیتای سئو (مثلاً `https://apoint.ir`) |

## 🎰 استخر چندکلیدی (تیم‌های شریک)

چند نفر روی یک استقرار کار می‌کنند و یک کلید به سقف نرخ می‌خورد؟ کلیدها را در **همان یک متغیر** `ZAI_API_KEY` و **با پرانتز** از هم جدا کنید:

```env
ZAI_API_KEY="(کلید-اول)(کلید-دوم)(کلید-سوم)(کلید-چهارم)(کلید-پنجم)"
```

- هر تعداد کلید (۵، بیشتر یا کمتر) پذیرفته می‌شود؛ کلیدهای تکراری حذف می‌شوند
- **هر درخواست** از یک کلید **رندوم** شروع می‌شود → بار به‌طور طبیعی بین کلیدها پخش می‌شود
- اگر کلید خطای سهمیه/نرخ داد، به‌طور خودکار کلید بعدی امتحان می‌شود؛ در نهایت پیام فارسی «سرورهای موتور هوش مصنوعی آرشام پوینت در این لحظه شلوغ است» نشان داده می‌شود
- جداکننده‌های ویرگول، خط عمودی و خط جدید هم پذیرفته می‌شوند، ولی پرانتز فرمت رسمی است
- کلیدها فقط سمت سرور خوانده می‌شوند و هرگز به مرورگر ارسال نمی‌شوند

## 🗄 اتصال Supabase (نسخه اصلی)

1. یک پروژه در [supabase.com](https://supabase.com) بسازید
2. در **SQL Editor** محتوای [`supabase/schema.sql`](supabase/schema.sql) را اجرا کنید (جدول `presentations` + RLS)
3. برای فروش اشتراک، محتوای [`supabase-subscriptions.sql`](supabase-subscriptions.sql) را هم اجرا کنید (جدول اشتراک‌ها + RLS)
4. سه متغیر Supabase را در `.env` (یا Vercel) پر کنید — تمام!

## ▲ استقرار روی Vercel

```bash
git init && git add . && git commit -m "Arsham Point"
git remote add origin https://github.com/<username>/arsham-point.git
git push -u origin main
```

سپس در Vercel پروژه را Import کنید و متغیرهای جدول بالا (Supabase + استخر کلیدها + پرداخت) را در **Settings → Environment Variables** وارد کنید و یک بار **Redeploy** بزنید.

راهنمای کامل‌تر: [`README-DEPLOY.md`](README-DEPLOY.md) یا داخل خود اپ، دیالوگ «راهنمای استقرار» در صفحه حساب من.

## 💳 پلن‌ها و پرداخت

| پلن | قیمت | محدودیت ارائه | امکانات |
|---|---|---|---|
| رایگان | ۰ تومان | ۳ در روز (پنجره لغزان ۲۴ ساعته) | قالب هوشمند + دو حالت متنی/تصویری + نشان «آرشام پوینت» در خروجی |
| حرفه‌ای | ۱۴۹ هزار تومان / هر ۳۰ روز | نامحدود | انتخاب دستی ۱۲ قالب و نوع اسلایدها، خروجی بدون نشان برند |

دکمه خرید اول به `/checkout` (بررسی سفارش: مبلغ، دوره ۳۰ روزه، شرایط خرید با چک‌باکس) می‌رود و سپس به درگاه زرین‌پال. پس از پرداخت موفق، اشتراک ۳۰ روزه خودکار فعال می‌شود. جزئیات: [`README-DEPLOY.md`](README-DEPLOY.md).

```
    ├── mode.ts             # تشخیص حالت + پارس استخر کلیدهای پرانتزی

    ├── deck-styles.ts      # ۱۲ قالب طراحی + ۱۲ رنگ غالب
    ├── plan.ts             # سهمیه‌ها (۳/روز رایگان، دوره ۳۰ روزه pro)

supabase/schema.sql         # جدول + RLS برای پروداکشن
supabase-subscriptions.sql  # جدول اشتراک‌ها + RLS
scripts/seed-demo.ts        # داده نمونه دمو
public/fonts/               # فونت وزیرمتن سلف‌هاست
```
